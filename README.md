# Практическая работа № 5. Классификатор и анализ метрик

## Цель работы

Построить модель бинарной классификации, оценить качество её предсказаний и подобрать порог классификации с учётом стоимости ошибок.

## Датасет

Используется Breast Cancer Wisconsin Diagnostic из библиотеки scikit-learn.

- 569 наблюдений.
- 30 числовых признаков.
- Целевой класс: 0 — доброкачественная опухоль, 1 — злокачественная опухоль.

## Используемые технологии

- Python
- pandas и NumPy
- scikit-learn
- Matplotlib и Seaborn

## Методика

1. Подготовка и разделение данных на обучающую, проверочную и тестовую выборки.
2. Обучение логистической регрессии с масштабированием признаков.
3. Получение вероятностей с помощью `predict_proba()`.
4. Построение ROC- и Precision-Recall-кривых.
5. Расчёт Accuracy, Precision, Recall, F1, ROC-AUC и Average Precision.
6. Подбор порога по стоимости ошибок на проверочной выборке.
7. Сравнение порогов 0.5 и выбранного порога на тестовой выборке.
8. Визуализация матрицы ошибок.

## Стоимость ошибок

В демонстрационном варианте стоимость FN принята равной 5, а FP — 1. Эти значения необходимо заменить, если преподаватель предоставил другие условия.

```bash
python -m pip install -r requirements.txt
```

Запустить программу:

